# Python Launcher

Meu primeiro projeto desenvolvido em Python feito para aprender sem compromisso.

Este projeto foi criado para colocar em prática os primeiros conceitos
que estou aprendendo na linguagem.

## O que ele faz

- Menu principal e submenus
- Navegação entre opções
- Abertura de URLs
- Abertura de aplicações
- Centralização de texto no terminal
- ASCII Art
- Validação de opções
- Uso de funções e loops

## Tecnologias

- Python
- VS Code

## Sobre

Este projeto foi desenvolvido como parte do meu aprendizado em Python.
Foi escrito por mim como meu primeiro projeto, sem geração de código por IA.

O objetivo não é ser um software complexo nem nada, apenas me testar no simples e registrar meu primeiro
passo na programação e acompanhar minha evolução.
