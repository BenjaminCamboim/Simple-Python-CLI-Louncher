# Python Launcher

Meu primeiro projeto desenvolvido em Python, feito sem compromisso enquanto
eu explorava a linguagem e começava a aprender programação de verdade.

Este projeto foi criado para colocar em prática alguns dos primeiros conceitos
que estou aprendendo em Python e registrar meu início com a linguagem.

## O que ele faz

- Menu principal e submenus
- Navegação entre opções
- Abertura de URLs
- Abertura de aplicações
- Centralização de texto no terminal
- ASCII Art
- Validação de opções
- Uso de funções e loops

## Tecnologias

- Python
- VS Code

## Sobre

Este projeto representa apenas o começo da minha experiência escrevendo código.
Foi feito por mim, sem geração de código por IA, como uma forma de experimentar
Python e começar a construir minhas próprias ideias.

A intenção é continuar aprendendo e transformar projetos cada vez mais
complexos em prática ao longo do tempo.

O objetivo não é ser um software complexo nem nada, apenas me testar no simples e registrar meu primeiro
passo na programação e acompanhar minha evolução.
